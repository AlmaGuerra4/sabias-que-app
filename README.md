App ¿sabías que? 
¿Qué es?
Es una aplicación móvil que muestra datos curiosos de diferentes categorías.

¿Cuál es su funcionalidad?
El usuario selecciona una categoría y puede visualizar datos curiosos aleatorios.

¿Cómo funciona?
* Se selecciona una categoría
* Se accede a un arreglo de datos
* Se genera un número aleatorio
* Se muestra un dato distinto cada vez

El código esta desarrollado en Objective-C.
